# 레벨 폭발 모험단 — 20보스 밸런스 최종 설계서 (v1.1)

- 문서 생성: `python3 doc_boss20.py` — 모든 숫자는 `boss20_config.json`(설정 원본)과 `SIM_RESULT.txt`(`python3 sim_boss20.py --runs 300` 출력)에서 스크립트가 끌어왔다. 손으로 옮긴 숫자는 없다. 끝의 `verify_doc_boss20.py` 가 문서와 설정의 일치를 검사한다.
- 파일: `boss20_config.json`(수치 전부: stats·formulas·caps·exp_curve·combat·run·items·stones·builds·monetization·pvp·boss_rush·monsters 60·bosses 20·routes) / `sim_boss20.py`(판 시뮬레이터, 의뢰자가 직접 돌릴 수 있음) / `gen_boss20.py`(수치 생성·앵커 보정·`--check` 재생성 검증) / `SIM_RESULT.txt`(§13 원문).
- 뼈대: B_dopamine (앵커 보정·체력바·타격 상한·피버·need(L)=10(1+L/1000)^0.3·3길). 이식: A: 흡혈 초당 상한 max(5%, 0.8×흡혈률), 험로 루프 에너지(2전투 −2 + 보스 +5), 숨은 보스 조건 4종, 치명 관통/장갑 보스, 도박 구역 1회 소진 / C: PvE/PvP 상한표 + pvp_disabled, 누진 사망 비용 3·4·5·6, 보스 고유 정수(+5 이상), 3연속 실패 천장, 7일 무료 체험·순간이동권·기록의 책·보스 러시 / D: 보스 성향(목표 초 ×, 공격 ×), 행운 보너스 '포인트 2배 당첨 p≤0.5', 제단 입장 체력 가득, 하위 5→상위 1 교환, 워프 제단, --check 재생성 검증, 재처치 무사망 +1 강화석.
- 네 설계안(A 로그라이트·B 도파민·C 경제/PvP·D 수학)과 세 심사(J1 플레이어·J2 수치·J3 라이브옵스)를 거쳐 B 를 뼈대로 통합한 결과물이다. 충돌은 수치 심사(J2) 기준을 우선했다.

## 1. 설계 철학

**한 줄:** 레벨은 한 판 안에서 1 → 수백억까지 터지게 두되(첫 판 7,482, 가운데 풀클리어 8847.2만, 20보스 완주 311.98억), **보스전만은 반드시 19.9~43.8초짜리 장면**으로 고정하고, 판이 끝나면 남는 것은 장비 20종·강화·강화석·정수·기록뿐이다.

기준선(v8) 시뮬이 보여 준 다섯 문제와 이 설계의 답:

| 기준선 문제 | 원인 | 해법 | 시뮬 증거(§13) |
|---|---|---|---|
| (a) 1보스 부트스트랩 불가(장비 0 승률 0%) | 1보스 HP 20,000·공 6,000 이 '엄니검 보유자' 기준 | 모든 보스를 **그 보스를 처음 만날 때 자연스럽게 가진 장비(이전 보스 아이템)** 기준으로 역산(앵커 보정). 1보스는 장비 0 기준 | A표: 장비 0, 1보스 승률 100%, 25.5초, 사망 0.51 |
| (b) 보스전 0.6~13초, 드라마 없음 | 피해 상한이 없어 장비 1개로 즉사 | **타격당 피해 상한(장갑) 3~5%** + 체력바 3~5개 + 전환 무적 0.8~1.5초 + 그로기·브레스·보호막·가시·저주·재생·타이머·광란·소환·흡혈·거울 기믹 | 자연 19.9~43.8초, 풀장비 +10 중간값 최단 11.1초, 한 방 없음 |
| (c) 흡혈·범위가 죽은 아이템 | 1:1 결투·1초 전투 | 전투 1:N(최대 3마리, 군단 루프는 항상 떼), 범위 = **동시 타격 수**, 흡혈 = **초당 회복 vs 초당 피격**(초당 상한 = max(5%, 0.8×흡혈률) — 공속이 아니라 흡혈 투자가 상한을 올림) | K-0: 흡혈 송곳니 획득 → 다음 보스 승리 51%→96%, 거인 망토 86%→92%; J표 흡혈 균형 사망 0.95 < 균형 1.57 |
| (d) 벽 아니면 허수아비 | 장비 배율이 단계 배율을 압도 | 장비는 배율·공속·흡혈·범위·경험치로 분산 + 합산 상한(caps) + 체력바·장갑으로 하한. 장비 −1 / 자연 / 풀장비 3단 체감 | A·B표(부족): 2~3번째 보스에서 소진, C표(자연) 사망 0.02~1.23, E표(풀) 사망 0.27 |
| (e) 인플레이션 체감은 장점 | — | 경험치 표로 바꾸되 need(L)=10×(1+L/1000)^0.3 의 완만한 곡선 → 초반 1전투 +수십, 후반 +수억 | §3 표: 1단계 첫 전투 뒤 89, 10단계 보스 뒤 6456.9만, 군단 끝 298.51억 |

통합에서 지킨 원칙:
1. **보상은 리듬으로 온다.** 전투 끝 → 레벨 티커 0.8초 → 걷기 → 다음 전투. 보스는 등장 3초 → 19.9~43.8초 드라마 → 문 4초. 첫 판 3.2분, 가운데 풀클리어 9.7분, 20보스 완주 18.1분.
2. **보스는 숫자가 아니라 장면이다.** 장갑 때문에 풀 +10 이라도 최소 20~34타, 중간값 11.1초 이상. 체력바가 깨질 때마다 화면이 멈추고, 그로기/브레스/폭주 타이머가 '지금 때려 / 지금 피해 / 서둘러'를 만든다.
3. **난이도는 계단이 아니라 경사.** 자연 장비 기준 보스마다 사망 0.02~1.23, 도달 71~100%. 보스 성향(탱커·유리대포·균형)으로 19.9~43.8초에 분산.
4. **선택이 결과를 바꾼다.** 7칸(반지 2)에 20종, 보스별 정답 아이템이 다르다(보호막→공속, 가시→치명, 저주→확정 치명, 흡혈 봉인→피해감소, 소환→범위). 빌드 5종이 전부 20보스 클리어 100% 이면서 사망·시간·레벨이 갈린다(J표). 함정 빌드(공격 몰빵·행운 몰빵·행운 0 탱커)는 시뮬로 표시해 UI 경고로 쓴다.
5. **험로는 에너지 광산.** 루프 구간 = 2전투 −2 + 보스 +5 = 순이익 +3. 장비를 갖추고 들어가면 20보스 한 판이 열리고(E-2 100%), 장비 없이 들어가면 표지판(권장 레벨)이 말린다.
6. **과금은 결과를 안 바꾼다.** 시작 에너지 +1 조차 팔지 않는다(H표 측정). 꾸미기·뽑기·강화석·보호권 없음. 파는 것은 시간·정보·기록·도전권.
7. **PvP 는 같은 코드, 다른 상한 열.** caps.pve / caps.pvp 16항목. 결투는 레벨 100,000 고정 + 분배 비율·장비·강화만. 5빌드 상성 36~63%.

**구조 요약:** 한 판 = 마을 → 가운데 길 10구간(각 4전투 + 문 보스) → 5단계 광장에서 질풍 루프(5구간 × 2전투 + 보스, 920 stud 돌아 광장 복귀) → 10단계 광장에서 군단 루프(같은 구조, 최종 보스). 루프는 선택이며 조건부 보스 4(B13·B14·B18·B19)가 '공략 목표'를 준다.

## 2. 능력치·전투 공식 전부 (닫힌 형식, JSON `stats` / `formulas` / `combat` / `caps`)

### 2.1 능력치 (레벨 1당 포인트 3, 자동 분배 기본 비율 체:힘:행:흡 = 1.0:2.0:0.5:0.5)
| 능력치 | 기본 | 1포인트당 | 기본 자동 비율 | 효과 |
|---|---|---|---|---|
| 체력 | 100 | +10 | 1.0 | 최대 체력 = (100 + 10×체력pt) × 장비 체력 배율 |
| 힘 | 10 | +2 | 2.0 | 공격력 = (10 + 2×힘pt) × 장비 공격 배율. 피해 = 공격력 × U(0.9,1.1) × 치명 배율 |
| 행운 | 1 | +1 | 0.5 | 치명타 확률, 레벨업 '행운! 2배 당첨' 확률, 정수 추가 드롭, (PvP) 회피 |
| 흡혈 | 0 | +1 (포인트 P) | 0.5 | 포인트 P → 흡혈% = 30%×P/(P + 1.0×레벨 + 50) (장비와 합산; 균형 분배 ≈9%, 흡혈 2배 분배 ≈13%, 몰빵 ≈20%). 초당 회복 상한(0.8×흡혈률)을 함께 올린다 |

**예시 계산 — 레벨 1,000, 균형 분배, 행운 당첨 없음, 장비 없음:** 포인트 2,997 → 체력 749·힘 1,498·행운 375·흡혈 375.
최대 체력 = 100 + 10×749 = **7,592**, 공격력 = 10 + 2×1,498 = **3,007**, 행운 = 1 + 375 = **376**, 흡혈 포인트 P = 375.
(실제 판에서는 '행운!' 당첨으로 포인트가 ×1.20 안팎 더 들어온다 — 2.2 참고.)

### 2.2 공식표
| 항목 | 식 | 예시(레벨 1,000 균형) | 비고 |
|---|---|---|---|
| 피해 | 공격력 × U(0.9,1.1) × (치명이면 치명 배율) | 3,007 × 0.9~1.1 → 2,706~3,308 (치명 5,413~6,615) | 질풍검은 U(0.7,1.5). 다중 타격은 대상마다 따로 굴림 |
| 치명타 확률 | min(60%, 5% + 60%×행운/(행운 + 0.5×레벨 + 40) + 장비) | 5% + 60%×376/(376+500+40) = **29.6%** | 레벨에 상대적 → 행운 비율이 같으면 어느 레벨에서도 같은 치명. 폭풍 정령 −10%p |
| 치명타 피해 | min(×4.0, ×2.0 + 장비) | ×2.0 (광전사 반지 +0.5 → ×2.5, 종언의 정령 +0.3) | PvP 상한 ×3.0 |
| 행운! 2배 당첨 | 레벨 1 오를 때마다 p = min(50%, 0.5×행운/(행운 + 0.5×레벨 + 50)) 로 그 레벨의 포인트 3 → 6 | p = 20.3% → 레벨당 기대 포인트 3×(1+0.203) = **3.61** (×1.20) | 상한 ×1.5, 레벨 무관(M-1). 서버는 레벨마다 주사위, 고레벨은 '행운 ×n' 묶음 표시. PvP 결투는 당첨 없음 |
| 흡혈률 | min(30%, 30%×P/(P + 1.0×레벨 + 50) + 장비) | 30%×375/(375+1,000+50) = **7.9%** (+송곳니 5% = 12.9%) | 균형 ≈3%, 흡혈 2배 분배 ≈6%, 몰빵(비율 0.75) ≈13% 로 수렴(레벨 ≫ 50 일 때 P/레벨 = 3×비율/비율합) |

## 3. 경험치·레벨 곡선 (`exp_curve`)

### 3.1 식 (서버는 누적 경험치가 아니라 레벨만 저장하고, 획득 시 E(L)+Δ → L(E) 로 복원)
- 레벨 L → L+1 필요 경험치: **need(L) = 10 × (1 + L/1000)^0.3**
- 레벨 L 도달 누적 경험치: **E(L) = 7692.3 × ((1 + L/1000)^1.3 − 1.0013)**  (E(1) = 0)
- 역함수(반복문 없음): **L(E) = 1000 × ((E/7692.3 + 1.0013)^(1/1.3) − 1)**, 소수점 버림.
- 왜 a=0.3: a=0 이면 경험치=레벨(순수 인플레이션), a=1 이면 보통 RPG. 0.3 은 "경험치 ×4.6 마다 레벨 ×3.2" — 10단계에서도 한 전투에 수백만 레벨이 오르고, 경험치 ×1.5 왕관은 레벨 ×1.37 로 눌려 들어가 폭주하지 않는다.

## 4. 한 판 구조 (`run` / `routes`)

### 4.1 에너지 (판의 수명)
시작 에너지 16, 전투 승리 −1, 사망 n번째 = min(6, 3+(n−1)) → 3,4,5,6,6…(1~2번은 전략, 3번부터 벌), 가운데 보스 +4, 루프 보스 +5(그 전투는 −1 없음). 루프 구간 = 2전투 −2 + 보스 +5 = 순이익 +3 → '장비 갖춘 뒤 들어가는 에너지 광산'. 사망 누진 카운터는 광장(루프 입·출구)을 지날 때 0 으로 초기화('광장 휴식': 한 장(章) 안에서 3번부터 벌). 에너지 0 또는 복귀 = 판 종료(레벨 1·포인트 0, 장비·강화·강화석·정수·기록 유지). 문은 이번 판에 그 보스를 잡아야 열림. 조건부 보스가 등장하지 않은 구간은 문이 바로 열린다(보상 없음).

| 사건 | 에너지 | 비고 |
|---|---|---|

## 6. 보스 20종

### 6.1 수치 산출 방식 (`design_anchors_note_ko`, `bosses[].anchor`)
몬스터 체력 = hp_k × (구간 첫 전투 직후 기대 공격력), 공격력 = atk_k × (같은 시점 기대 최대 체력). 보스 체력 = 자연 장비 기대 DPS(피버 가동률 포함) × 목표 초(성향 배율 적용) × (1 − 전환 초/목표 초), 공격력 = dps_k × 간격 × 도착 기대 체력 × 성향 공격 배율. 기대값은 경험치 곡선 + 자연 장비(이전 보스 아이템 자동 장착) + 균형 분배로 계산. 질풍 루프는 가운데 5구간 뒤 경험치에서, 군단 루프는 10구간 뒤 경험치에서 이어진다. 마지막으로 앵커 플레이어로 보스전을 40회 시뮬해 중간 전투 시간이 목표 초가 되도록 보스 체력(거울 기사는 T)을 보정했다(calibrated_secs_median).
- 성향(D 안): 탱커 = 목표 초 ×1.3·공격 ×0.75, 유리대포 = 목표 초 ×0.7·공격 ×1.25, 균형 = ×1/×1. 배분: 탱커 B03, B06, B09, B13, B17, B19 / 유리대포 B02, B05, B08, B12 / 균형 나머지 10.
- 보정 절차: ① 자연 판 60회로 도착 레벨 재측정(`arrival_level_measured_median`, p10~p90) ② 앵커 플레이어 40회 결투로 공격 배율 격자+이분 탐색(`atk_calib_mult`, 사망 목표 `death_target` 가운데 0.6 / 루프 0.5 / B01 0.35 / B13 0.3 / B19 0.35; 사망 0 평탄 구간이면 큰 배율) ③ 체력 2회 반복 보정(중간 전투 시간 = 목표 초, `calibrated_secs_median`). `death_curve` 에 배율별 사망이 기록되어 있어 노브를 돌릴 때 참고한다.
- 사망 목표를 0.3~0.6 으로 둔 이유: '죽으며 깎기'가 가능하되(v6 규칙 유지) 보스마다 평균 1회 미만이어야 누진 사망 비용(3,4,5,6)이 판을 끝내지 않는다. 자연 진행 실측 0.02~1.23(C표).

### 8.5 공략 예시 — 선택이 결과를 바꾸는 장면
1. **바람 정령을 얻은 다음 판(B03 에테르 드래곤)**: 보호막 5타 × 체력바 3개 = 15타가 피해 0. 공속 ×1.43 이면 보호막 벗기는 시간이 5.0초 → 3.5초. K-0: 다음 보스 승리 24%→85%.
2. **에테르 왕관을 얻은 다음 판(B06)**: 경험치 ×1.5 = 레벨 ×1.37 = 모든 능력치 ×1.37. K-0: 18%→89%, 평균 처치 보스 5.09→6.70.
3. **심연의 수호자(B09)**: 보스 흡혈 35%·내 흡혈 ×0.5·관통 ×1.2 제한. 광전사 반지를 빼고 용암 망토(피해 −15%·반격 10%)와 체력 분배로. 자연 진행 사망 0.33(C표) — 장비를 바꾸지 않으면 '행운 도박'이 가장 고전하는 보스.
4. **폭풍 와이번 25초 컷 → 회오리 정령왕 → 무사망 → 운명의 구미호**: 질풍 루프의 조건부 체인. 자연 장비로 25초 컷은 100%, 정령왕 무사망은 37%(풀장비 100%). 정령왕은 소환 2마리×2회라 광풍 망토(3마리) 없으면 6마리 상대 — 거인 망토(2마리)로도 사망이 줄어든다.
5. **군단 루프 전 장비 재구성**: 군단 파쇄 망토(떼 +25%·3마리) + 피의 성배(초당 회복 상한 8%) + 군주의 부적(에너지 +3/+1). K-0 피의 성배: 사망 4.80→3.77. 영혼 왕관은 '안전(행운의 왕관) vs 기록(최종 레벨 234.33억→304.82억)'의 선택.
6. **워프 판**: 황제 드래곤 3회 처치 뒤 10단계 광장에서 시작(레벨 ×0.9, 에너지 12) → 군단 루프 5보스 5.1분·클리어 95%·사망 2.17(Q표). 숙련자의 모바일 한 세션.

## 11. PvP 대비 (JSON `pvp`, `caps.pvp`, `items[].pvp_disabled`) — 3차 출시

마을 결투장: 두 플레이어 모두 결투 레벨 100,000 으로 정규화(각자 저장된 분배 비율대로 포인트), 장착 장비·강화만 그대로. 주는 피해 ×0.08, 한 타 ≤ 상대 최대 체력 12%(최소 9타), 공속 ≤2.2, 흡혈 ≤30%(PvE 와 같음 — 20% 로 자르면 흡혈 빌드의 유일한 결투 장점이 사라져 전패했다), 초당 회복 ≤6%, 치명 ≤50%·×3, 피해감소 ≤40%, 반격 ≤10%, 관통 없음, 피버 없음. 회피 = max(10%, 치명 확률 ×0.35) ≤25% (행운 = 결투 방어 스탯, 행운 0 도 하한 10%; 0.5 면 행운이 흡혈을 압도해 흡혈 균형이 전패). 결투 포인트는 레벨 100,000 분량(300,000)으로 고정(행운 당첨 없음 — 당첨은 PvE 전용). 결투 흡혈: 타격당 회복 = 흡혈률 × √(내 최대 체력 × 상대 최대 체력) × 12% (PvE 의 '피해 비례' 회복은 공격형만, '내 체력 비례'는 체력형만 유리해져 승률이 0/100 으로 갈림 — 기하평균이 둘을 중립화, 시뮬 L표로 확인), 초당 ≤6%. 60초 후 체력% 높은 쪽 승. pvp_disabled 효과(경험치·에너지·상한 돌파·부활·보스 경험치) 무효. 3v3 에서 범위 2마리·스플래시 15%.
